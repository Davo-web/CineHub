# CineHub

CineHub — современный веб-интерфейс для поиска и просмотра информации о фильмах и сериалах, вдохновлённый стриминговыми платформами.

Проект создан для практики frontend-разработки, изучения адаптивной вёрстки, компонентного подхода и организации CSS-архитектуры.

---

## Возможности

- Адаптивный интерфейс
- Поиск фильмов и сериалов
- Компонентная структура
- Модульная CSS-архитектура
- Использование методологии БЭМ
- Подготовка к дальнейшему подключению API

---
